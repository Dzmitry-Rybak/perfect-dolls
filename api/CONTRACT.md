# Контракт API

Фронтенд ждёт именно эти эндпоинты. Каждый соответствует функции
из `src/lib/api.js` — при подключении бэкенда меняются только тела
функций, сигнатуры остаются.

Базовый путь: `/api`. Формат: JSON, UTF-8.

---

## Каталог

### `GET /api/dolls`
Соответствует `getDolls({ category })`.

| Параметр | Тип | По умолчанию | Описание |
|---|---|---|---|
| `category` | string | `all` | `all` · `doll` · `arttoy` · `clothing` |

**200** — массив кукол:

```json
[{
  "id": 1,
  "slug": "mothwing",
  "name": "Мотылёк",
  "category": "doll",
  "price": 240,
  "status": "available",
  "height": 32,
  "year": 2026,
  "materials": ["хлопок", "винтажные пуговицы"],
  "tagline": "Ночная гостья с пыльцой на плечах",
  "story": "Сшита в две бессонные ночи…",
  "tags": ["мотылёк", "ночь"],
  "accent": "#C9BFD6"
}]
```

`status` — одно из `available` · `preorder` · `sold`.
`height` может быть `null` (для одежды).
`accent` — HEX, используется как акцентный цвет карточки.

### `GET /api/dolls/:slug`
Соответствует `getDoll(slug)`. **200** — один объект куклы, **404** — если нет.

### `GET /api/dolls?featured=true&limit=4`
Соответствует `getFeatured(limit)`. Работы для главной, без проданных.

### `GET /api/categories`
Соответствует `getCategories()`.

```json
[{ "id": "all", "label": "Все" }]
```

## Конструктор

### `GET /api/constructor/parts`
Соответствует `getConstructorParts()`.

```json
{
  "basePrice": 180,
  "layers": [{ "id": "body", "label": "Тело", "hint": "основа и оттенок ткани" }],
  "parts": {
    "body": [{ "id": "body-linen", "name": "Небелёный лён", "priceDelta": 0, "color": "#D8C9B4" }]
  }
}
```

Порядок `layers` = порядок отрисовки слоёв снизу вверх. Менять его на
бэкенде нельзя, не поправив `DollCanvas.jsx`: `id` деталей захардкожены
в SVG-компонентах.

### `POST /api/builds`
Соответствует `submitBuild(config)`.

**Тело:**

```json
{
  "body": "body-linen",
  "hair": "hair-bob",
  "eyes": "eyes-pearl",
  "mouth": "mouth-stitch",
  "outfit": "outfit-pinafore",
  "accessory": "acc-none"
}
```

**201:**

```json
{ "id": "build_m1x2y3", "status": "received", "config": { } }
```

Цену считать на сервере заново, а не брать с клиента.

## Заявка: кукла, портрет, готовый сквид

### `POST /api/commissions`
Соответствует `submitCommission(values, kind)`.

**Формат: `multipart/form-data`** — иначе не передать файлы.
Фронт собирает `FormData` сам, поля приходят плоским списком. Полный
список полей каждой анкеты — в `src/data/commissionForm.js`; ниже
главное.

| Поле | Тип | Обязательное | Примечание |
|---|---|---|---|
| `kind` | string | да | `doll` · `portrait` · `squid` · `build` — от него зависит состав полей |
| `name`, `email` | string | да | у всех анкет |
| **куклы** | | | |
| `instagram`, `message` | string | нет | |
| `dolls` | string | да | `1` · `2` · `3` · `4` |
| `country` | string | да | |
| `path` | string | да | `steps` — заполняли по шагам, `file` — всё в одном документе |
| `brief` | file[] | при `path=file` | PDF или Word |
| `colours`, `mouth`, `scary` | string | нет | `mouth`: `regular` · `stitched` · `bloody`; `scary`: `true` · `false` |
| `skinPhotos`, `hairPhotos`, `outfitPhotos`, `shoesPhotos`, `detailsPhotos` | file[] | нет | только снимки |
| `skinNote`, `hairNote`, `outfitNote`, `shoesNote`, `detailsNote` | string | нет | |
| `dollName`, `packaging`, `extra` | string | нет | |
| `companion` | string | нет | `true` — мини-сквид к кукле (+$75); описание в `companionNote` |
| `reserve` | string | нет | `true` — бронь места с доплатой 50% |
| **портреты** | | | |
| `people` | string | да | `1` · `2` · `3` · `4` |
| `pets` | string | нет | `0` · `1` · `2` · `3` · `4` |
| `files` | file[] | нет | снимки и PDF |
| **готовые сквиды** | | | |
| `model`, `price` | string | да | приходят от карточки модели |
| `ship_*` | string | да | адрес доставки: `street` `unit` `city` `state` `country` `postcode` `phone` |
| `sameInvoice` | string | — | `false` — счёт на другие данные, они в `invoice_*` |
| **сквид из конструктора** (`build`) | | | поля адреса и счёта — как у готового сквида |
| `build` | string | да | сквид словами, по строке на пункт |
| `buildJson` | string | да | сырая сборка из конструктора; цену по ней пересчитать на сервере |
| `price` | string | да | цена, которую видел человек, — только для сверки |

В каждом поле с файлами — до 5 файлов, ≤ 8 МБ каждый, ≤ 20 МБ на поле.
Допустимые типы: снимки — `image/jpeg`, `image/png`, `image/webp`,
`image/heic`; документы — `application/pdf`, `application/msword`,
`application/vnd.openxmlformats-officedocument.wordprocessingml.document`.

**201:**

```json
{
  "id": "RD-MTPZSLN7",
  "status": "received",
  "files": [{ "name": "референс.png", "size": 4821 }]
}
```

**Что обязан сделать бэкенд**

1. **Проверить файлы заново.** Ограничения на клиенте — удобство, а не защита:
   их обходит любой прямой запрос. Проверять размер, количество и реальный тип
   по содержимому, а не по расширению и не по заголовку `Content-Type`.
2. **Проверить обязательные поля** и формат почты. Обязательные зависят от
   `kind` — см. таблицу выше: у кукол `name`, `email`, `dolls`, `country`,
   `path`, у портретов `people`, `name`, `email`. Число людей и животных на портрете
   ограничено четырьмя: список на клиенте больше не предлагает «и больше»,
   но проверить потолок обязан сервер.
3. **Ограничить частоту** — форма открыта всем, без лимита её зальют спамом.
4. **Отправить письмо Рите** с полями и вложениями — на адрес из
   `EMAIL.commissions[kind]` (`src/data/site.js`): куклы — на кукольный
   ящик, портреты и сквиды (готовые и из конструктора) — на основной.
   Заказчику — подтверждение с номером заявки.
5. **Сохранить заявку** до отправки письма: если почтовый сервис отвалится,
   заявка не должна пропасть.

## Подписка на открытие приёма

### `POST /api/subscriptions`
Соответствует `subscribe(email, topic)`. Форма живёт в закрытом блоке
заказа на страницах «Куклы» и «Портреты».

**Тело:**

```json
{ "email": "her@example.com", "topic": "dolls" }
```

`topic` — `dolls` · `portraits`. Разделы открывают в разное время,
поэтому подписки раздельные: письмо про портреты не должно уходить
тому, кто ждал куклу.

**201:**

```json
{ "status": "subscribed", "email": "her@example.com", "topic": "dolls" }
```

**Что обязан сделать бэкенд**

1. **Проверить формат почты** заново — проверка на клиенте нестрогая
   намеренно и защитой не является.
2. **Не плодить дубли.** Повторная подписка тем же адресом на тот же
   раздел — это `201` и та же запись, а не вторая: человек просто не
   помнит, подписывался он или нет.
3. **Ограничить частоту** — форма открыта всем и без лимита станет
   способом слать письма чужими руками.
4. **Дать отписку.** В каждом письме — ссылка с одноразовым токеном,
   работающая без входа куда-либо.
5. **Не подтверждать чужой адрес молча.** Подписка вступает в силу
   после перехода по ссылке из письма-подтверждения, иначе адрес
   любого человека можно записать в рассылку.

## Контент

### `GET /api/gallery`
Соответствует `getGallery()`. `span` — размер плитки: `sm` · `wide` · `tall`.

```json
[{ "id": "g1", "title": "Пуговичная Луна", "year": 2025,
   "note": "Уехала в Гент", "accent": "#E8C46A", "span": "tall" }]
```

> **Запланировано: постраничная выдача галереи.** Когда появится бэкенд,
> `/gallery` должна показывать по 6 работ на странице и дальше — следующая
> страница, а не весь архив разом. Запрос: `GET /api/gallery?page=2&limit=6`
> (вместе с фильтром `kind`, если он выбран). Ответ — работы страницы и
> общее число, чтобы нарисовать переключатель страниц:
> `{ "items": [...], "total": 23, "page": 2, "limit": 6 }`. Номер страницы
> держать в адресе (`/gallery?kind=doll&page=2`), чтобы ссылку можно было
> отправить и кнопка «назад» возвращала на ту же страницу. Сейчас
> галерея берёт всё из Sanity одним запросом (`getGallery()` в
> `src/lib/api.js`) — это место и менять.

### `GET /api/squid-models`
Соответствует `getSquidModels()`. Готовые дизайны из коллекций —
показываются на странице «Сквиды» между конструктором и архивом.

```json
[{ "id": "bluet", "name": "Bluet", "collection": "coraline",
   "price": 110, "photo": null }]
```

`collection` — готовая подпись под именем, строкой. Порядок в массиве
= порядок на странице. `photo` — `null`, пока снимка нет: карточка
показывает пустую рамку, а не пропадает.

Записей не больше восьми — на широком экране они стоят одним рядом.
Ограничение стоит в админке, но проверить его обязан и сервер.
Снимок приходит со ссылкой на полный размер: по нажатию на карточку
он открывается во весь экран.

### `GET /api/faq`
Соответствует `getFaq()`.

```json
[{ "q": "Сколько ждать куклу на заказ?", "a": "От четырёх до восьми недель…" }]
```

## Ошибки

Единый формат, фронт уже умеет его показывать:

```json
{ "error": { "code": "NOT_FOUND", "message": "Кукла не найдена" } }
```

Коды: `400` валидация · `404` нет объекта · `409` уже продано · `500` прочее.
