# Rita Dolls

Витрина мастерской авторских кукол ручной работы.
Эстетика: dark whimsical / pastel goth / creepy cute / sewing.

**Текущий этап:** только фронтенд на моках. Бэкенда пока нет —
в `api/` лежит контракт, под который он будет писаться.

---

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # сборка в dist/
npm run preview  # посмотреть собранное
```

Нужен Node ≥ 20.19.

---

## Что где

```
api/            контракт будущего бэкенда (CONTRACT.md) и заметки (README.md)
src/
  lib/api.js    ★ единственная точка перехода мок → бэкенд
  lib/format.js валюта, статусы, склонение, наклон карточек
  lib/useAsync  общий хук загрузки для всех страниц
  styles/       tokens.css (палитра, шрифты, ритм) + global.css (reset, зерно)
  data/         мок-данные — при подключении бэкенда удаляются
  context/      корзина (localStorage)
  components/   ui/ · layout/ · catalog/ · home/ · constructor/
  pages/        8 маршрутов + 404
```

### Слой данных

Компоненты **никогда** не импортируют `src/data/*` напрямую — только
через `src/lib/api.js`. Функции возвращают `Promise` с задержкой 180–400 мс,
поэтому состояния загрузки написаны и проверены заранее.

Подключение бэкенда = замена тел функций в `api.js` на `fetch`.
Сигнатуры не меняются, компоненты не трогаются. Подробности — `api/README.md`.

## Деплой

Vercel определяет Vite автоматически: сборка `npm run build`, каталог `dist`.

`vercel.json` обязателен. Маршрутизация клиентская, поэтому в `dist` лежит
только `index.html` — папок `constructor/`, `catalog/` и прочих там нет.
Без правила `rewrites` прямой заход на `/constructor` или перезагрузка
страницы упираются в файловую систему и отдают 404. Переходы внутри
сайта при этом работают, потому что их обрабатывает JS, — из-за чего
проблема легко проходит незамеченной.

Правило безопасно для статики: у Vercel `rewrites` применяются **после**
проверки файловой системы, поэтому `/assets/*` и `/button-eye.svg`
отдаются как настоящие файлы.

> Побочный эффект: несуществующий адрес отдаёт HTTP 200 с нашей страницей
> 404 вместо честного статус-кода. Для SPA это норма; если понадобится
> настоящий 404, его должен отдавать бэкенд.

## Дизайн-система

### Палитра

Снята пипеткой с референсов Риты (сами файлы в репозитории не хранятся).
Розовый `#FF96C9` и чёрный `#151515` — фактические цвета бренда,
взятые с её картинки со шрифтами.

Все токены в `src/styles/tokens.css`. Проверены на контраст:
основной текст 15.6:1, акцент 9.7:1, цена 11.6:1 — все AAA.
`--plum` (4.47:1) помечен как **только декор и крупный текст**.

Тема одна, тёмная. Светлого режима нет намеренно.

### Шрифты — важное ограничение

Сайт на русском, поэтому **каждый шрифт обязан иметь кириллицу**.
Собственные шрифты Риты (ButtonsPatches, floozy, WizardsMagic,
Pretty On the Inside) и Mystery Quest — **латиница только**: на кириллице
они молча падают в системный serif и вся декоративность теряется.

Поэтому:

| Переменная | Шрифт | Где |
|---|---|---|
| `--font-display` | Amatic SC | заголовки (кириллица) |
| `--font-latin` | **Mystery Quest** | только логотип — там латиница |
| `--font-accent` | Alice | H3, цифры, ярлыки |
| `--font-body` | Cormorant Garamond | описания |
| `--font-ui` | Rubik | кнопки, цены, фильтры |
| `--font-hand` | Caveat | конструктор, подписи маркером |

Замена шрифтов = правка блока в `tokens.css` + ссылки в `index.html`.

### Фактурные приёмы

Взяты из референсов, а не из общего набора «тёмных тем»:
зерно холста · рамки-строчки · глаз-пуговица как сквозной мотив ·
наклон карточек как приколотых фотографий · акварельные кляксы ·
рисованная спираль · тетрадь в клеточку (только конструктор).

## Конструктор

Слои снизу вверх: тело → волосы → глаза-пуговицы → рот → наряд → спутник.
Отрисовка в `components/constructor/DollCanvas.jsx`, данные в
`data/constructorParts.js`.

Сборка синхронизируется с URL через `useSearchParams`: ссылку можно
переслать, перезагрузка не теряет выбор.

> При изменении `id` деталей на бэкенде нужно править и `DollCanvas.jsx` —
> формы слоёв привязаны к конкретным `id`.

## Доступность

- Контраст проверен, значения в `tokens.css`
- `:focus-visible` виден на всём сайте, у вариантов конструктора — через `:has()`
- `prefers-reduced-motion: reduce` отключает всё движение
- FAQ на нативном `<details>` — работает с клавиатурой и поиском по странице
- Ссылка «к содержимому» в шапке

Проверено автоматически: 9 маршрутов × 4 ширины (375 / 768 / 1024 / 1440) —
без горизонтального переполнения, без безымянных кнопок и изображений.
