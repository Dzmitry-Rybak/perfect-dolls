# cutesmokey

Сайт мастерской: плюшевые сквиды, коллекционные куклы и рисованные портреты.
**Сайт на английском** — 95% заказов из англоязычных стран.

**Текущий этап:** только фронтенд на моках. Бэкенда нет — в `api/` лежит
контракт, под который он будет писаться.

---

## Запуск

```bash
npm install
npm run dev      # http://localhost:5173
npm run build
npm run preview
```

Нужен Node ≥ 20.19.

## Окна заказов

Куклы и портреты открываются окнами, а не постоянно. Состояние —
в **`src/data/shopState.js`**:

```js
dolls: { open: false, window: 'late October 2026', note: '…' }
```

`open: false` → кнопка заменяется на блок «заказы закрыты» с примерной
датой и подпиской. `open: true` → открывается анкета.

Это запасной вариант: настоящее состояние живёт в админке, раздел
**Настройки**, и файл читается, только если Sanity недоступен.

## Правовые страницы

`/privacy`, `/terms`, `/copyright` — один компонент `src/pages/Legal.jsx`,
тексты в **`src/data/legal.js`**. Ссылки на них стоят в подвале,
он есть на каждой странице.

**Перед запуском заполнить `TRADER` в `src/data/legal.js`**: имя,
на которое зарегистрировано дело, адрес, страна, регистрационный
номер, VAT и надзорный орган по защите данных. Маргарита
зарегистрирована в ЕС, а значит эти сведения обязаны быть на сайте
(Directive 2000/31/EC, art. 5). Пустое поле не печатается вовсе,
а при `npm run dev` наверху правовых страниц висит красный список
того, чего не хватает. Там же, в `POLICY`, лежат числа, на которые
ссылаются все три текста: депозит, сроки хранения, возраст.

Анкета на заказ просит обязательную галочку (права на присланные
фото + прочитана политика) и необязательную — «не показывайте
готовую работу публично». `public/robots.txt` закрывает сайт от
сборщиков данных для обучения моделей; на странице авторских прав
это же сказано словами.

⚠️ Шрифты грузятся с серверов Google (`index.html`), то есть IP
каждого посетителя уходит к Google. В политике это честно написано;
чтобы убрать совсем — положить woff2 в `public/` и раздавать со
своего домена.

## Админка

Sanity Studio, каталог **`studio/`**. `npm run dev` — локально,
`npm run deploy` — выложить. Схемы правятся в `studio/schemas/`,
после правки админку нужно выложить заново.

| Раздел | Что меняет |
|---|---|
| **Работы** | архив: сквиды, куклы, портреты. Снимки, названия, порядок |
| **В наличии** | полка «Available now» на главной. Пусто — вместо карточек приписка |
| **Главная** | большой снимок вверху и картинки четырёх разделов (+ второй кадр при наведении) |
| **Страницы разделов** | по три работы на `/squids`, `/dolls`, `/portraits`. Пусто — первые три по порядку |
| **Настройки** | открыты ли заказы на кукол и портреты, когда откроются |

Первое заполнение «Главной» и «Страниц разделов» — `node scripts/seed-home.mjs`
(ссылается на уже загруженные снимки работ, ничего не перезаливает и
не трогает то, что уже выбрано).

Сайт переживает и пустую админку, и недоступный Sanity: в сборку
вшиты снимки из `public/art` и `src/data/*`. Откат виден в консоли
строкой `[cutesmokey] …: не удалось прочитать из Sanity`. Новый адрес
сайта нужно добавить в CORS origins проекта — см. шапку `src/lib/sanity.js`.

## Конструктор сквида

Схема обведена вручную по эскизам Риты в `src/components/squid/SquidCanvas.jsx`.
Двадцать одна кликабельная зона.

- Клик по детали → палитра рядом. По умолчанию красится **вся группа**
  (одно щупальце → все семь)
- Переключатель **Mix colours** → поштучная раскраска
- Мех: шесть фиксированных цветов. Пуговица и нитка: расширенная палитра
- Подвески выбираются **по номеру** с фотографии коллекции: на превью
  1–3 см их всё равно не различить
- Цена считается на ходу по прайсу Риты

Данные — `src/data/squidBuilder.js`.

> **Заглушки, ждущие Риту:** расширенная палитра пуговиц, две палитры
> лент (атласные и ажурные), финальный список простых паттернов.

## Деплой

Vercel определяет Vite автоматически: сборка `npm run build`, каталог `dist`.

`vercel.json` обязателен. Маршрутизация клиентская, поэтому в `dist` лежит
только `index.html` — папок `constructor/`, `catalog/` и прочих там нет.
Без правила `rewrites` прямой заход на `/constructor` или перезагрузка
страницы упираются в файловую систему и отдают 404. Переходы внутри
сайта при этом работают, потому что их обрабатывает JS, — из-за чего
проблема легко проходит незамеченной.

Правило безопасно для статики: у Vercel `rewrites` применяются **после**
проверки файловой системы, поэтому `/assets/*` и `/button-eye.svg`
отдаются как настоящие файлы.

> Побочный эффект: несуществующий адрес отдаёт HTTP 200 с нашей страницей
> 404 вместо честного статус-кода. Для SPA это норма; если понадобится
> настоящий 404, его должен отдавать бэкенд.

## Дизайн-система

### Палитра

Снята пипеткой с референсов Риты (сами файлы в репозитории не хранятся).
Розовый `#FF96C9` и чёрный `#151515` — фактические цвета бренда,
взятые с её картинки со шрифтами.

Все токены в `src/styles/tokens.css`. Проверены на контраст:
основной текст 15.6:1, акцент 9.7:1, цена 11.6:1 — все AAA.
`--plum` (4.47:1) помечен как **только декор и крупный текст**.

Тема одна, тёмная. Светлого режима нет намеренно.

### Шрифты — важное ограничение

Сайт на русском, поэтому **каждый шрифт обязан иметь кириллицу**.
Собственные шрифты Риты (ButtonsPatches, floozy, WizardsMagic,
Pretty On the Inside) и Mystery Quest — **латиница только**: на кириллице
они молча падают в системный serif и вся декоративность теряется.

Поэтому:

| Переменная | Шрифт | Где |
|---|---|---|
| `--font-display` | Amatic SC | заголовки (кириллица) |
| `--font-latin` | **Mystery Quest** | только логотип — там латиница |
| `--font-accent` | Alice | H3, цифры, ярлыки |
| `--font-body` | Cormorant Garamond | описания |
| `--font-ui` | Rubik | кнопки, цены, фильтры |
| `--font-hand` | Caveat | конструктор, подписи маркером |

Замена шрифтов = правка блока в `tokens.css` + ссылки в `index.html`.

### Фактурные приёмы

Взяты из референсов, а не из общего набора «тёмных тем»:
зерно холста · рамки-строчки · глаз-пуговица как сквозной мотив ·
наклон карточек как приколотых фотографий · акварельные кляксы ·
рисованная спираль · тетрадь в клеточку (только конструктор).

## Две линейки

**Куклы** — только на заказ. Каталог работает как портфолио: всё, что там
показано, уже уехало к своим людям. Цена рядом с работой — ориентир, а не
ценник. Купить со страницы нельзя, корзины на сайте нет: единственное
действие — открыть анкету.

**Мягкие игрушки** — за них отвечает конструктор. Сейчас он собирает куклу
(осталось с прошлого этапа) и ждёт SVG деталей осьминога.

## Анкеты

Две разные формы, потому что вопросы почти не пересекаются:
**кукла** (4 шага) и **портрет** (3 шага). Описаны данными в
`src/data/commissionForm.js` — формулировки правятся там.

Файлы: до 5 штук, 8 МБ каждый, 20 МБ суммарно. Дубли и перевес
отсеиваются с объяснением.

Плюс **подписка** на открытие заказов — `POST /api/subscribe`.

> Отправка замокана. Заработает с бэкендом по `api/CONTRACT.md`.

## Доступность

- Контраст проверен, значения в `tokens.css`
- `:focus-visible` виден на всём сайте, у вариантов конструктора — через `:has()`
- `prefers-reduced-motion: reduce` отключает всё движение
- FAQ на нативном `<details>` — работает с клавиатурой и поиском по странице
- Ссылка «к содержимому» в шапке

Проверено автоматически: 9 маршрутов × 4 ширины (375 / 768 / 1024 / 1440) —
без горизонтального переполнения, без безымянных кнопок и изображений.
